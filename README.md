# Phishing-URL-Detection
Machine Learning-based phishing URL detection system using Random Forest and Streamlit to classify URLs as Phishing or Legitimate.
"Phishing URL Detection" is a Machine Learning-based system designed to identify potentially phishing URLs.  
The system extracts important URL-level features such as URL length, IP address, subdomain, port, and HTTPS-related patterns.  
A Random Forest classifier is trained to classify URLs as "Phishing" or "Legitimate".  
The trained model is integrated with a "Streamlit" web application for easy URL analysis.  
Users can enter a URL and instantly receive the predicted classification through the dashboard.  
The URL-only model achieved **74.17% accuracy** on the held-out test dataset.
